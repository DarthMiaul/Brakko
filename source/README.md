# Source-code context

`app.py` and `index.html` come from the user-provided MergeMeme project. The code has been privacy-scrubbed to remove names of unrelated prior experiments. The app is not a byte-identical copy of the code used in the run, and its full asset library is not included. It is provided to show the intended processing logic, not as a guaranteed standalone reproduction. No `.env`, API key, authentication configuration, or user uploads are included.

The run was invoked through one user-operated OpenRouter account. The seven providers did **not** conduct an official joint collaboration.
